### Improvements & Features (v0.1.3-beta)

* **Millisecond Precision (.xxx)**: Timers now display milliseconds by default (`00:15.250 (IGT) │ 00:15.264 (RTA)`), giving full high-resolution speedrun split feedback.
* **Smoother HUD Refresh**: Action bar updates every 2 ticks (10 FPS) for responsive millisecond tracking while keeping CPU overhead imperceptible (<0.005% of tick budget).
* **Millisecond Toggle**: Added `/timer millis <true|false>` command and in-game Mod Menu button to easily toggle millisecond visibility on or off.
* **Smart Millisecond Input**: `/timer set` now supports decimal seconds and milliseconds (e.g. `/timer set 90.5` or `/timer set 01:23.450`).
